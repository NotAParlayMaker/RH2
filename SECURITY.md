# Security

This repository has Lean source and shell scripts. The scripts download files from https://alpo.ge and check their SHA-256 before use.

If you find a problem in a script or a workflow, do not open a public issue. Use the private report form at https://github.com/tamnd/riemann-lean/security/advisories/new.

If you find a soundness problem in the Lean proof, for example a hidden axiom, it is not a security issue. Open a public issue, so that people can see it.
